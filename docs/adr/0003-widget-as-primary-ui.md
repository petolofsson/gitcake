# Floating widget as primary UI

The primary interface is a compact always-on-top floating widget, not a traditional application window. The widget shows all tasks (in-progress highlighted, others dimmed) and handles the full task lifecycle inline. A main window exists but is accessed only from the system tray/menu bar. A preferences window handles font, colors, and dark/light mode.

The core value of the app is staying visible while the developer works — a persistent ambient reminder of what they are supposed to be working on. A traditional window that gets buried under other apps defeats this purpose. The widget is the product; the main window is maintenance.
